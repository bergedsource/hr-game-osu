# You're the HR Manager

An interactive negotiation game built for my MGMT 455 (Influence & Negotiation) UnEssay at Oregon State University.

You get eight corrective-action cases. Every ruling moves three meters: compliance, relationships and precedent. At the end the game places you on the Dual Concerns Model and compares how often you waived or traded a penalty with a student organization's discipline records.

Play it: https://hr-game-osu.vercel.app/

The cases are fictional. Each one is a workplace version of a settlement type from a student organization's discipline records, with no names or identifying details.
